# sidd.zst — Cinematic Cyberpunk Portfolio

Premium interactive portfolio with a Hollywood-style opening sequence.

**Access Level : SUPERUSER**

---

## Experience Flow

1. **Black void** (1s) — pure silence
2. **Giant metallic S** appears — neon green edges, film grain, vignette
3. **S comes alive** — inner light sweeps, volumetric glow, reflections
4. **Zoom + orbital camera** — S scales up, camera swings from the LEFT around to BEHIND the letter
5. **Pass behind / through the S** — abstract light tunnels, motion depth (~5.5s)
6. **Fade to black**
7. **Linux boot sequence** — typed headlines, progress bars, privilege escalation
8. **SUPERUSER reveal** — sidd.zst + tags
9. **ENTER SYSTEM** → full website unlocks

- HTML5

## Features

### Cinematic Intro
- Perspective camera + 3D projected ribbons
- Particle field with depth
- Light streaks and volumetric glow
- Film grain + vignette
- Smooth cubic easing, motion blur simulation

### Boot
- Realistic kernel log
- Character-by-character typing on key lines
- Animated progress bar + percent
- Privilege Escalation → Authentication Successful → Access Level : SUPERUSER

### Website
- Matrix rain + particle network background
- Custom cyber cursor + mouse glow
- Scanlines + noise overlays
- Glassmorphism cards
- Interactive terminal (sid@blackarch:~$)
- 3D tilt project cards
- Scroll-reveal animations
- Skill progress bars
- Learning timeline
- Contact + copy email
- Easter egg: click logo 5x → root shell
- Fully responsive
